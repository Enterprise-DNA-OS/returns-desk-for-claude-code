# Review consumer-rights evidence, safety holds and retention dates

Run `npm run returns -- compliance [--json]`. All commands accept `--json` for machine-readable results.

Read the case or item history first. Use explicit identifiers when a name matches more than one record. Present the real output, keep unknown values visible and never add currencies together.

Read docs/compliance.md. Findings are missing evidence and internal controls, not legal conclusions. Never deny consumer rights based on a shop return window. Unsafe stock remains quarantined.
