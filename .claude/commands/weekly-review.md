# Prepare the Monday returns review from three reports

Run `npm run returns -- weekly-review`. All commands accept `--json` for machine-readable results.

Read the case or item history first. Use explicit identifiers when a name matches more than one record. Present the real output, keep unknown values visible and never add currencies together.

This runs attention, inspection-queue and compliance. Summarise the owners of late cases, units awaiting inspection, major-defect choice gaps, quarantine and retention reviews. Name the evidence behind each proposed next action. Do not infer that a refund happened from a decision.
