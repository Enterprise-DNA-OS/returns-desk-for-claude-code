# Make the returns desk yours

Read CLAUDE.md, the relevant command, migration and tests. Ask the operator for the field, rule or terminology they want. Export a new private snapshot first. Add the next numbered migration, never edit an applied one. Apply it to a disposable database, add checks for the new behaviour, and run npm test. Apply the reviewed migration to the working database only within the operator's request. Update the CLI, relevant slash command, view and document together. Read the result back from the database.

A case country correction, a new return disposition or an evidence amendment needs an explicit record of the old value, new value, actor and reason. Keep original receipt and decision evidence. Consumer-rights checks and quarantine controls must not disappear as an incidental change. Update docs/compliance.md when a reviewed rule changes.
