# Prepare an internal remedy summary without sending

Run `npm run returns -- draft-resolution <case>`. All commands accept `--json` for machine-readable results.

Read the case or item history first. Use explicit identifiers when a name matches more than one record. Present the real output, keep unknown values visible and never add currencies together.

Output stays in drafts/. This is an internal review summary, not an automatic customer letter. Check the case, assessment and external completion before adapting it. Never send.
